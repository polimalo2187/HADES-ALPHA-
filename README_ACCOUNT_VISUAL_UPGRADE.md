# HADES Alpha — Account Visual Upgrade

Base usada: `HADES-ALPHA-egress-top50-scanner-v1`.

## Objetivo

Elevar visualmente el apartado Cuenta para que esté al nivel del resto de HADES Alpha.

## Cambios

- Hero premium para Centro de cuenta.
- Cards visuales por sección:
  - Suscripción
  - Gestión de riesgo
  - Rendimiento
  - Ajustes
  - Referidos
  - Billing
  - Órdenes
  - Recompensas
  - Timeline
  - Oraculum
  - HADES Sentinel
  - Soporte
  - App instalada
- Gradientes, glow, bordes premium y tarjetas con identidad visual.
- No se tocó lógica de pagos, premium, scanner, señales, Oraculum ni Sentinel.
